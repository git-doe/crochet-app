# Crochet App

A simple, handy Android app for crochet creators to calculate product pricing and manage projects. Built using HTML, CSS, and JavaScript, and compiled using [html2app.dev](https://html2app.dev).

---

## Features

- **Price Calculator:** Quickly calculate accurate pricing for handmade crochet items based on material costs, hours spent, and desired wage.
- **Project Storage:** Keep track of ongoing and completed projects, materials used, and custom order notes in one place.
- **Clean Launch Screen:** Features an interactive splash screen designed for smooth navigation.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Build Tool / Compiler:** [html2app.dev](https://html2app.dev)
- **Target Platform:** Android

---

## Getting Started

### Prerequisites

To test or modify the source files locally, all you need is a web browser. To build the Android APK:
1. Ensure your web assets (`index.html`, CSS, and JS files) are ready.
2. Use [html2app.dev](https://html2app.dev) to package the project into a native Android APK.

### Project Structure

```text
├── index.html       # Main app entry point
├── css/             # Styling & layout
├── js/              # Price calculator & project storage logic
└── assets/          # Images, icons, and UI assets
```

---

## Usage

1. Open the app on your Android device.
2. Navigate to the **Price Calculator** tab, input your yarn/material costs and time spent to generate a fair sales price.
3. Use the **Project Manager** to log active commissions or personal WIPs (works in progress).
